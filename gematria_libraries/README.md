# Gematria Libraries

This directory contains the JSON libraries required for the Ruach Equations. Each file is a collection of Hebrew words and phrases from the Tanach that are thematically relevant to the library's specific concept.

The fundamental principle is to associate each parameter of the equations (e.g., Faith, Adeptship) with a curated set of words and/or phrases that embody that concept. The numerical value used in the calculations is the raw gematria score of these words, derived by summing the values of their constituent Hebrew letters.

## What is Included

Only words and phrases that positively and directly relate to a library's theme are included in these libraries, which correspond to the variables in the "Equation for Action" and the "Equation for Perception".
