# Hebrew Holy Bible – Tanach

JSON representation of the Hebrew Bible scraped from BibleHub.

Contents:
- `individual_books/` – Each book as a JSON file of chapters and verses.
- `torah.json`, `prophets.json`, `writings.json`, `minor_prophets.json` – Grouped collections.

Related Reference Materials:
- The primary legend for morphology and parsing tags can be found in `/reference_materials/hebrew_parsing_tag_legend.json`.
- A complete ledger of all unique words in the Tanach and their Gematria values is in `/reference_materials/word_gematria_ledger.json`.

These files are the primary data source for all work performed on the Hebrew Holy Tanach.
